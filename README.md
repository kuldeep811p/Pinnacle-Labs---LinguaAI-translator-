# LinguaAI – Real-time Translator Web App

LinguaAI is a sleek, browser-based translation application that breaks language barriers with real-time AI-powered translations. Supporting **100+ languages**, it offers a beautiful dual-panel interface, text-to-speech functionality, translation history, and smart offline fallbacks — all without requiring any API keys.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌍 **100+ Languages** | Full language support including English, Hindi, French, Spanish, Japanese, Arabic, and more |
| ⚡ **Real-time Translation** | Powered by MyMemory's free translation API |
| 🔊 **Text-to-Speech** | Listen to both source text and translated output |
| 📜 **Translation History** | Last 10 translations stored with language labels & timestamps |
| 🎯 **Quick Language Pills** | One-click target language selection (Hindi, French, Spanish, etc.) |
| 🔄 **Swap Languages** | Invert source/target languages with a single click |
| ⌨️ **Keyboard Shortcut** | `Ctrl + Enter` to trigger translation instantly |
| 📊 **Live Statistics** | Tracks total translations, words translated, and unique languages used |
| 💾 **Offline Fallback** | Common phrase translations work even without internet |
| 📋 **Copy to Clipboard** | One-click copy translated text |
| 🎨 **Premium UI** | Glassmorphic cards, gradient accents, smooth animations |

---

## 🚀 How to Use

1. **Download** the `translator_app.html` file
2. **Double-click** to open in any modern browser (Chrome, Firefox, Safari, Edge)
3. **Type or paste** text in the left panel
4. **Select languages** from dropdowns or click quick language pills
5. **Click Translate** (or press `Ctrl + Enter`)
6. **Listen** using 🔊 buttons, **copy** with 📋, or **swap** languages with ⇄

> 💡 **No installation, no API keys, no backend required!**
